# Estrategia de contenido

Libros sobre cómo **generar ideas, elegir formatos, mantener consistencia y crecer** con tu contenido.

Aquí encajan ideas sobre creación de contenido, pilares (TOFU/MOFU/BOFU), crecimiento en redes y hábitos de publicación.

**Ejemplos de libros para esta carpeta:**
- Libros sobre creación de contenido y crecimiento en redes sociales
- Libros sobre la estrategia de pilares de contenido

> Agrega cada libro como un archivo `nombre-del-libro.md` dentro de esta carpeta.
