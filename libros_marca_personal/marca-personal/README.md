# Marca personal

Libros sobre cómo **construir, posicionar y diferenciar** una marca personal auténtica.

Aquí encajan ideas sobre mostrar tu proceso en público, construir autoridad y conectar con tu audiencia.

**Ejemplos de libros para esta carpeta:**
- *Show Your Work!* — Austin Kleon
- *Expert Secrets* — Russell Brunson

> Agrega cada libro como un archivo `nombre-del-libro.md` dentro de esta carpeta.
