# Guionización

Libros sobre **escritura de guiones, ganchos, copywriting y storytelling**.

Aquí encajan ideas para escribir guiones que enganchen, estructuras narrativas (como el puente de la epifanía) y técnicas de copy.

**Ejemplos de libros para esta carpeta:**
- Libros de copywriting y escritura persuasiva
- Libros de storytelling y estructura narrativa

> Agrega cada libro como un archivo `nombre-del-libro.md` dentro de esta carpeta.
> Las estructuras reutilizables de guion viven en [`../../guiones`](../../guiones).
