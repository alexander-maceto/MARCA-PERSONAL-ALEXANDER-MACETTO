# Embudos

Libros sobre **embudos de venta, ofertas y conversión**: cómo llevar a tu audiencia desde que te descubre (TOFU) hasta que te compra (BOFU).

Aquí encajan ideas sobre embudos, ofertas irresistibles, valor percibido y llamados a la acción.

**Ejemplos de libros para esta carpeta:**
- *DotCom Secrets* — Russell Brunson
- *$100M Offers* — Alex Hormozi

> Agrega cada libro como un archivo `nombre-del-libro.md` dentro de esta carpeta.
