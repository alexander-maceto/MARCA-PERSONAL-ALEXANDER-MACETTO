# Filmmaking

Libros sobre **grabación, cámara, iluminación, composición y edición de video**.

Aquí encajan ideas técnicas y estéticas para que tu contenido tenga el look cinematográfico de tu marca (ver la sección de identidad visual en [`../../estrategia`](../../estrategia)).

**Ejemplos de libros para esta carpeta:**
- Libros de cinematografía e iluminación
- Libros de edición y lenguaje audiovisual

> Agrega cada libro como un archivo `nombre-del-libro.md` dentro de esta carpeta.
