# Miedo y perfeccionismo

Libros sobre el **miedo al juicio, el miedo a exponerse y el perfeccionismo** que paralizan a mi avatar.

Aquí encajan ideas sobre vulnerabilidad, resistencia creativa y el temor a mostrarse. Útil para crear contenido que valide ese miedo y empuje a la acción.

**Ejemplos de libros para esta carpeta:**
- *The War of Art* — Steven Pressfield
- *Daring Greatly* — Brené Brown

> Agrega cada libro como un archivo `nombre-del-libro.md` dentro de esta carpeta.
