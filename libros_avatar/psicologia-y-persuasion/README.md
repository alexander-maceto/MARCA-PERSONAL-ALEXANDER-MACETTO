# Psicología y persuasión

Libros sobre **cómo piensa, decide y se convence** mi avatar, y cómo romper sus objeciones de forma ética.

Aquí encajan ideas sobre toma de decisiones, sesgos, persuasión y comportamiento humano. Útil para entender por qué mi avatar posterga y cómo motivarlo a actuar.

**Ejemplos de libros para esta carpeta:**
- *Influence* — Robert Cialdini
- *Thinking, Fast and Slow* — Daniel Kahneman

> Agrega cada libro como un archivo `nombre-del-libro.md` dentro de esta carpeta.
