# Claridad y pensamiento

Libros sobre la **parálisis por análisis, la claridad mental, el enfoque y la necesidad de orden** de mi avatar.

Aquí encajan ideas sobre simplificar, priorizar y enfocar, para entender por qué mi avatar sobreanaliza y cómo darle estructura para avanzar.

**Ejemplos de libros para esta carpeta:**
- *Essentialism* — Greg McKeown
- *Deep Work* — Cal Newport

> Agrega cada libro como un archivo `nombre-del-libro.md` dentro de esta carpeta.
