# Hábitos y disciplina

Libros sobre **constancia, disciplina y la dificultad de empezar y sostener** un hábito.

Aquí encajan ideas para entender por qué a mi avatar le cuesta ser constante y cómo ayudarlo a tomar acción y mantener el ritmo sin sacrificar su estándar.

**Ejemplos de libros para esta carpeta:**
- *Atomic Habits* — James Clear
- *The Power of Habit* — Charles Duhigg

> Agrega cada libro como un archivo `nombre-del-libro.md` dentro de esta carpeta.
