# Plantilla: Estructura de Guion Base

Estructura reutilizable para guiones de contenido (video corto, reel, post, etc.).

## 1. Gancho (primeros 3 segundos)
- Frase o pregunta que detiene el scroll.

## 2. Contexto / Problema
- Conecta con el dolor o deseo del avatar.

## 3. Desarrollo / Valor
- La idea, el tip o la historia. Aquí va el contenido central.

## 4. Prueba / Autoridad
- Dato, ejemplo, cita de un autor o resultado que respalde lo dicho.

## 5. Cierre + Llamado a la acción
- Qué quieres que haga la audiencia (seguir, comentar, guardar, comprar).
